# Sora

SaaS de gestion multi-restaurant. Le backend Django/DRF inclut maintenant les
comptes, le menu, les commandes, la cuisine, les paiements, le stock, la
production, l'audit et les prévisions.

Voir le [guide du backend](backend/README.md) pour installer l'environnement,
configurer les services, lancer les vérifications et connaître les API
disponibles. Les opérations de déploiement, sauvegarde et restauration sont
décrites dans [la procédure d'exploitation](backend/docs/operations.md).
